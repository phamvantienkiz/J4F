So sánh Kiến trúc AI Agent cho Backend (FastAPI)

Tìm kiếm giải pháp tối ưu nhất về Tốc độ (Speed) và Độ chính xác (Accuracy) cho Product

So sánh 3 Hướng tiếp cận cho Agent Backend

A

Semantic Router + Rule-based Engine (Nhanh & Chính xác nhất)

Cách hoạt động: 1. Dùng 1 LLM Call duy nhất (hoặc regex/semantic search) để phân loại Ý định (Intent) và trích xuất thực thể (Color, Size, Price, Country) thành JSON dạng Pydantic.
2. Sử dụng mã Python thuần (deterministic code) để truy vấn Supabase, tính toán Margin/Ship và xếp hạng. Không cho LLM tự quyết định gọi công cụ.
3. Dùng 1 LLM Call cuối cùng để chuyển dữ liệu thô thành câu trả lời Tiếng Việt trôi chảy.

🚀 Latency: < 1.5s | 🎯 Độ chính xác: ~99% (Math/Logic tuyệt đối)
B

LangGraph dạng State Machine / DAG (Hybrid)

Cách hoạt động: Vẫn dùng LangGraph để quản lý trạng thái hội thoại đa lượt, nhưng các bước chuyển đổi giữa các Node (Node transitions) là cố định và lập trình sẵn bằng code Python (Deterministic DAG). LLM chỉ được dùng ở các Node cụ thể để phân tích câu hỏi hoặc viết câu trả lời, không dùng LLM để tự chọn công cụ chạy.

🚀 Latency: 2s - 3s | 🎯 Độ chính xác: ~95% (Dễ kiểm soát luồng)
C

Autonomous ReAct Agent (Kiểu cũ - Không khuyến nghị cho Product)

Cách hoạt động: LLM chạy vòng lặp suy nghĩ (Reasoning-Acting Loop). LLM tự quyết định khi nào gọi Tools (ví dụ: `search_catalog_tool`, `get_sla_tool`), tự đọc kết quả và lặp lại cho đến khi tự thấy đủ thông tin.

⚠️ Latency: 5s - 10s (Chạy nhiều vòng lặp) | 🎯 Độ chính xác: ~75% (Dễ sai lệch logic toán học)

So sánh Chi tiết tiêu chí

Tiêu chí A. Semantic Router + Python Engine B. Deterministic LangGraph C. Autonomous ReAct Agent
Độ trễ (Latency) Cực thấp (1 LLM Call chính) Trung bình (1-2 LLM Calls) Rất cao (Vòng lặp >= 3 LLM Calls)
Khả năng tính toán toán học Chính xác 100% (Tính bằng code Python) Chính xác 100% (Tính bằng code Python) Dễ sai sót (LLM tự tính hoặc tự truyền tham số)
Độ ổn định luồng (Stability) Tuyệt đối (Luồng đi cố định) Rất cao (Luồng qua State Machine) Kém (LLM có thể bị lặp vô hạn hoặc gọi sai tool)
Khả năng xử lý hội thoại tự do Đủ dùng (Dựa trên context truyền vào) Rất tốt (LangGraph quản lý session state) Tự do nhất (Nhưng rủi ro cao)
