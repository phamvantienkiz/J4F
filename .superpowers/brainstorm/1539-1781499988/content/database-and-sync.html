Lựa chọn Database Free & Cơ chế Sync Dữ liệu

Thiết kế hệ thống lưu trữ và đồng bộ hóa tự động dữ liệu BurgerPrints sau mỗi 6-12 tiếng

1. Lựa chọn Cloud Database PostgreSQL Miễn Phí

Các dịch vụ cung cấp PostgreSQL Managed hoàn toàn miễn phí, phù hợp cho môi trường Production của dự án:

A

Supabase (Khuyến nghị)

Gói Free: 500MB bộ nhớ DB, 50,000 MAU Auth miễn phí, không tự động sleep sau vài phút không hoạt động (chỉ tạm dừng nếu không hoạt động trong 1 tuần). Rất ổn định cho chatbot chạy liên tục.

B

Neon.tech

Gói Free: 0.5 GiB lưu trữ, kiến trúc Serverless Postgres. Rất dễ sử dụng, tuy nhiên DB sẽ tự động chuyển sang chế độ "sleep" sau 5 phút không có request, request tiếp theo sẽ mất 2-3 giây để khởi động lại DB.

2. Sơ đồ Luồng Đồng bộ (Sync Flow) & Cấu trúc Database

BurgerPrints API
Catalog & Shipping
→ (Gọi định kỳ)
FastAPI Backend
Sync Service & Scheduler
→ (Lưu trữ/Cập nhật)
PostgreSQL
Supabase / Neon
Các bảng dữ liệu (Tables) dự kiến:
  • Catalog: Lưu danh sách sản phẩm base (shortCode, name, displayName, category...).
  • Variant/SKU: Lưu các biến thể (size, color, baseCost, secondSidePrice, location/supplier...).
  • Location/Workshop: Lưu thông tin xưởng sản xuất (locationId, locationName, processingTime, SLA...).
  • ShippingRate: Lưu phí ship chi tiết theo từng quốc gia (countryCode, firstItemPrice, additionalItemPrice, SLA...).
  • ChatSession / ChatHistory: Lưu lịch sử chat của người dùng phục vụ hội thoại nhiều lượt.

3. Phương án Kích hoạt Sync (Triggering Cron Job)

Làm sao để hệ thống tự động chạy đồng bộ sau mỗi 6 tiếng hoặc 12 tiếng?

A

APScheduler chạy nền trong FastAPI

Sử dụng thư viện APScheduler trực tiếp trong ứng dụng FastAPI. Khi server khởi động, nó tự chạy background thread để đồng bộ. Đơn giản, không phụ thuộc dịch vụ ngoài, nhưng đòi hỏi server FastAPI phải chạy liên tục (không deploy lên serverless ngủ đông).

B

GitHub Actions / External Cron service (Ví dụ: cron-job.org)

Viết một endpoint bảo mật POST /api/v1/sync trên FastAPI (yêu cầu API Secret Key). Sử dụng một dịch vụ cron bên ngoài hoặc GitHub Actions định kỳ gọi tới endpoint này. Thích hợp cho cả môi trường serverless (như Render, Vercel, Fly.io) giúp tiết kiệm tài nguyên.
