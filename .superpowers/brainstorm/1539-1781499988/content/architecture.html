Sơ đồ Kiến trúc Hệ thống (Production Architecture)

Next.js (FE) kết nối trực tiếp với FastAPI (BE + DB + AI Agent) không qua NestJS

1. Sơ đồ Luồng dữ liệu (Data Flow Diagram)

Next.js (Frontend)
App Router, Tailwind CSS, TypeScript
UI Chatbot & Order Panel
⇆
FastAPI Backend (Python)
Uvicorn, Python 3.11+
APIs & LangGraph Multi-Agent
⇆
PostgreSQL Database
Prisma ORM (FE) / SQLAlchemy (BE)
Sessions & Products Cache
Chi tiết luồng hoạt động:
  1. User nhập câu hỏi trên Giao diện Next.js (Ví dụ: "Tìm T-shirt dưới $8 ship US").
  2. Next.js thực hiện gọi API POST /agent/chat trực tiếp sang FastAPI Backend.
  3. FastAPI nhận yêu cầu, tải Context hội thoại từ PostgreSQL (nếu có session trước) và chạy LangGraph Agent:
    • Intent Agent: Xác định ý định là tìm kiếm sản phẩm.
    • Catalog Agent: Gọi Public Catalog API v1 để lấy thông tin sản phẩm và phí ship.
    • Engine/Ranking: Lọc theo điều kiện (giá < $8, ship US), tính toán margin/SLA và xếp hạng.
  4. FastAPI trả về JSON có cấu trúc chuẩn (gồm nội dung chat dạng markdown, danh sách sản phẩm khớp, dữ liệu trung gian).
  5. Next.js render khung hội thoại và tự động mở bảng Order Draft Panel bên tay phải nếu phát hiện ý định tạo đơn hàng (đã che giấu dữ liệu nhạy cảm PII).

2. Lựa chọn Hướng phát triển CSDL & Đồng bộ hóa

Vì chúng ta chuyển sang mô hình Next.js gọi trực tiếp FastAPI, cơ sở dữ liệu PostgreSQL cần được chia sẻ hoặc quản lý đồng bộ:

A

Một DB PostgreSQL duy nhất (Khuyến nghị)

Cả Next.js (nếu cần xử lý DB nội bộ bằng Prisma) và FastAPI (sử dụng SQLAlchemy/SQLModel) đều kết nối trực tiếp vào một DB PostgreSQL. Đồng bộ schema bằng Prisma migrations.

B

FastAPI độc quyền quản lý Database

Database chỉ kết nối với FastAPI. Next.js hoàn toàn không có Database riêng, mọi thao tác lưu trữ (session, người dùng, tracking) đều đi qua API của FastAPI. Đơn giản hóa kiến trúc.

3. So sánh cấu trúc dự án mới

Ưu điểm Next.js + FastAPI

  • Đơn giản & Hiệu năng cao: Bỏ đi NestJS giúp giảm bớt một lớp proxy trung gian, giảm latency mạng.
  • Tập trung hóa AI: Toàn bộ logic RAG, Agent, Tools đều nằm ở FastAPI, tận dụng tối đa hệ sinh thái Python (LangGraph, Pandas).
  • Next.js mạnh mẽ: Sử dụng App Router và Server Actions để xử lý API Keys, Gateway bảo mật nếu cần.

Thách thức & Điểm lưu ý

  • Chia sẻ mô hình dữ liệu: Cần định nghĩa rõ schema chung giữa Prisma (TypeScript) và SQLModel (Python) để tránh lệch pha dữ liệu.
  • Quản lý Auth: Next.js sẽ phải đảm nhận việc quản lý User Session (ví dụ: dùng NextAuth) và ký JWT truyền sang FastAPI để xác thực.
