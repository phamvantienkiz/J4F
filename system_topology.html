Pipeline Chi Tiết Của AI Agent

Luồng nội bộ từ trên xuống cho phân tích intent, định tuyến geo-mùa vụ, trích xuất catalog có bảo vệ, token telemetry và serialize SSE.

graph TD
    INPUT["Yêu Cầu Người Dùng / Phiên Cold Start"] --> PARSER["Chuẩn Hóa Intent & Slot
(Ngôn Ngữ / Intent / Quốc Gia)"]
    PARSER --> GEO["Bộ Khớp Geo-Hemisphere
(Trích Xuất Tọa Độ Quốc Gia)"]
    GEO --> EMPTY{"Country Slot Có Trống Không?"}

    EMPTY -->|CÓ: Kích Hoạt Fallback| US["Áp Dụng Neo Market US Mặc Định"]
    EMPTY -->|KHÔNG| DATE["Đánh Giá datetime.date.today()"]
    US --> TREND["Bộ Định Tuyến Xu Hướng Toàn Cầu
(Back-to-School Bắc Bán Cầu / Winter Comfort Nam Bán Cầu)"]
    DATE --> TREND

    TREND --> SQL["Tối Ưu Truy Vấn SQL & Trích Xuất Dữ Liệu
(Khóa category nghiêm ngặt: WHERE product_type = target)"]
    SQL --> GUARD["Xác Thực Guardrails
(Ngăn lỗi mutation / lọc quá mức; giữ ma trận so sánh)"]
    GUARD --> TOKEN["Bộ Thu Thập Token Telemetry
(usage.prompt_tokens + usage.completion_tokens → meta.tokens_total)"]
    TOKEN --> SSE["Bộ Xử Lý Streamed SSE Payload
(chuỗi answer + metadata token + catalog items → React + Vite Frontend)"]

    class INPUT input
    class PARSER,GEO parser
    class EMPTY decision
    class US,DATE,TREND time
    class SQL,GUARD knowledge
    class TOKEN,SSE telemetry

Vòng Lặp Tương Tác Agent Và Tool

Luồng thực thi agentic từ FastAPI Gateway, phân tích intent, gọi tool cục bộ, tổng hợp context, gọi LLM và đóng gói SSE payload.

graph TD
    %% Khởi tạo luồng từ Gateway
    API["Cổng Kết Nối FastAPI Gateway
(Nhận Tin Nhắn & Trạng Thái)"] -->|Truyền Dữ Liệu Payload & State| AGENT["Luồng Xử Lý AI Agent
(Bộ Điều Phối Điều Khiển Trung Tâm)"]

    %% Giai đoạn Phân tích Ý định & Slot
    subgraph Layer_1 [NÃO BỘ AGENT - ĐỊNH TUYẾN & LẬP KẾ HOẠCH]
        AGENT --> PARSE_INTENT{"Phân Tích Ý Định & Slot Từ Khóa"}
        PARSE_INTENT -->|Ý định: Tìm kiếm / Check giá| SHIP_EMPTY{"Thiếu Quốc Gia Ship?"}
        SHIP_EMPTY -->|CÓ: Cần Hỏi Người Dùng| COUNTRY_TOOL[["Công Cụ: Tra Cứu Quốc Gia Ship Khả Dụng"]]

        PARSE_INTENT -->|Ý định: Tính Biên Lợi Nhuận| RE_CALC{"Người Dùng Đặt Giá Bán Lẻ Mới?"}

    %% Giai đoạn Gọi Tool Trích xuất Dữ liệu (Tool Invocation Loop)

        COUNTRY_TOOL -->|Đọc ShippingZone + Product Coverage| COUNTRY_OPTIONS["Gợi Ý Quốc Gia Có Thể Ship

        GEO_ROUTING -->|Kích Hoạt SQL Tool| SQL_TOOL[["Công Cụ: PostgreSQL Catalog Query"]]
        SQL_TOOL -->|Truy Vấn Dữ Liệu| DB_RAW[("Cơ Sở Dữ Liệu Supabase PostgreSQL
(Quét Ma Trận Sản Phẩm Gốc)")]
        DB_RAW -->|Trả Về Danh Sách Hàng| GUARD_CHECK["Bộ Lọc Kiểm Soát Guardrails

        RE_CALC -->|Đúng: Kích Hoạt Math Tool| MARGIN_TOOL[["Công Cụ: Tính Toán Biên Lợi Nhuận"]]
        MARGIN_TOOL -->|Xử Lý Thuật Toán Tài Chính| MARGIN_META["Tính Toán Lợi Nhuận Thuần, Thuế & %Margin

    end

    %% Giai đoạn Tổng hợp Context & Gọi LLM Sinh Text
    subgraph Layer_3 [XỬ LÝ MÔ HÌNH LLM & STREAM DỮ LIỆU]
        CLARIFY_RESPONSE --> SERIALIZER
        GUARD_CHECK --> BUILD_CONTEXT["Bộ Tổng Hợp Context Sạch

        BUILD_CONTEXT -->|Gửi Prompt Đầy Đủ| LLM_GEN[["Mô Hình Ngôn Ngữ Lớn LLM API

        LLM_GEN -->|Stream Câu Trả Lời Về| TELEMETRY["Bộ Giám Sát Đo Lường Token

        TELEMETRY -->|Bổ Sung meta.tokens_total| SERIALIZER["Bộ Đóng Gói Dữ Liệu SSE Payload
(Hợp nhất Văn Bản + Hàng Hóa + Meta Token)"]
    end
